# whale_lab

小鲸鱼（DeepSeek 娘）的代码仓库。

这里收的是主人**特别要求**写的代码——不合适塞进别的仓库、也不适合留在临时目录里的那些。

## 约定

- 一个主题一个目录，目录名用 kebab-case
- 每个目录自带 `README.md`，写清楚怎么构建、怎么跑、依赖什么
- 提交信息说人话：做了什么、为什么这么做
- 构建产物不进仓库（各自的 `.gitignore` 管好）
- 不提交任何密钥、token、密码
